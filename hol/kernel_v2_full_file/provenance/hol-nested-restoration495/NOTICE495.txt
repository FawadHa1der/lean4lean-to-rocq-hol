Changed HOL Light port of raw local Rocq nested-restoration helpers.
This directory adapts rocq/NestedAdmission.v:8-37, with local-record and
extended-expression/lift dependencies from489 and447. See SOURCES495.txt.
Algorithmic upstream attribution also includes Lean4Lean/Inductive/Add.lean,
Mario Carneiro and Lean4Lean contributors, at the revision below.
The upstream Apache-2.0 LICENSE is included byte-for-byte.

The four requested helpers are structural HOL definitions. The fifth definition
is a total option eliminator for the free-variable case, not an oracle.
These operations perform raw syntax manipulation, not typing or admission.
The source is not wired into any executable checker. All HOL definitions and
28 prove scripts remain SOURCE ONLY / UNCOMPILED; no target result is claimed.
The Python code is two handwritten finite models with shared data/equality,
not extraction, evaluation of target HOL, a certified interpreter, or an
upstream Lean comparison. It uses no external tools, files, or network.

Representation boundary: all13 extended expression constructors, all4 binder
variants, nonDep, structured names, universe fields and metadata wrappers are
retained. Metadata PAYLOADS are absent already in local Rocq/syntax447.
Num-list string/name validity and the Rocq/HOL name-equality correspondence
remain external obligations. This is not lossless Lean serialization.

No full restore_nested_expr, environment, declaration metadata, candidate
detection493-494, or checked admission is implemented here. No native approval,
guard/authority, loader selection, or existing evidence is changed.
Session78 remains stopped; goal continuation is not native approval.
