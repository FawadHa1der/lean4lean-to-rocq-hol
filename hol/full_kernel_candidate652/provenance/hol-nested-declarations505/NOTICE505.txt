Changed HOL Light implementation of six local Rocq nested declaration helpers:
rocq/NestedAdmission.v:160-224, using full493 declaration/metadata records and
499 expression/type restoration. The immediate semantic reference is pinned
local Rocq source, not a claimed formal equivalence with upstream Lean4Lean.
The repository Apache-2.0 LICENSE is included unmodified.

All definitions and 22 proof/regression scripts are SOURCE ONLY / UNCOMPILED.
These helpers rebuild declarations; they do not implement checked admission,
decimal-indexed recursor naming, a complete kernel, or an external oracle.
The finite handwritten Python model is not HOL execution or Rocq extraction.
It explicitly reuses the inspected, pinned handwritten model499.py for existing
restoration behavior, so it is not an independent equivalence implementation.

Name components use num lists in HOL and text in the handwritten model.
The inherited447 syntax erases metadata payloads while retaining wrappers.
Wire/encoding fidelity, caller invariants, runtime loading, proof checking and
full Lean compatibility remain separate obligations. Held temporary needs
paths are not a selected/default integration or a complete runtime manifest.
