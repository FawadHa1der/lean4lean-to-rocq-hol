This prerequisite representation has all6 local Rocq universe constructors,
all4 binder-information variants, and13 expression constructors (the two literal
variants are separate). Names, binder information, let nonDep and metadata
wrappers are retained. As in Rocq, metadata payloads are erased; num-list string
encoding validity is external. This is not a lossless Lean runtime/serialization
model, an admission checker, or a claim of full Lean4Lean compatibility.
In particular, upstream Expr.eqv compares metadata payloads. Two different
payloads with the same body erase to the same local representation, which can
merge nested memoization keys. This is a representation/compatibility gap,
not a demonstrated unsound acceptance. A full-input port must retain payload
equality information or justify and enforce a restricted input domain.
